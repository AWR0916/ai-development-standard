# コーディング標準

## 共通規則

- リポジトリで採用したフォーマッター、静的解析、命名規則に従う。
- 変更の目的に不要なリファクタリングや依存更新を混在させない。
- 外部入力を信頼せず、境界で形式、範囲、長さ、権限を検証する。
- 秘密情報をコード、ログ、テストデータ、履歴へ含めない。
- エラーを握りつぶさず、利用者向け情報と運用向け情報を分離する。
- 公開API（Application Programming Interface）と複雑な判断には、目的や制約が分かる説明を加える。

## AI生成コード

AI生成コードも人が作成したコードと同じ品質基準を適用します。採用前に、正確性、境界条件、セキュリティ、ライセンス、依存関係、既存設計との整合を人が確認します。

## 完了条件

ビルド、静的解析、対象テスト、秘密情報検査が成功し、自己レビューで不要な変更やデバッグ情報がないことを確認します。
