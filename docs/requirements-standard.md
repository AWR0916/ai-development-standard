# 要件定義標準

## 必須事項

- **RQM-01（必須）** 解決する問題、利用者、期待価値、対象外を明記する。
- **RQM-02（必須）** 機能要件と非機能要件を分け、一意な識別子を付ける。
- **RQM-03（必須）** 各要件を観測可能な受入条件に変換する。
- **RQM-04（必須）** 性能、可用性、セキュリティ、プライバシー、アクセシビリティ、運用性を評価する。
- **RQM-05（必須）** 入出力データの所有者、機密区分、保存期間、削除方法を定める。
- **RQM-06（必須）** AIを利用する場合、許容できない出力、人的確認、停止条件を定める。

## 書き方

- **RQM-07（必須）** 「適切に」「高速に」「可能な限り」など、判定できない表現を避ける。
- **RQM-08（必須）** 数値化できない要件には、具体例と判断者を示す。

## 変更時の確認

- **RQM-09（必須）** 要件変更では、関連する設計、コード、テスト、運用手順への影響を確認する。
- **RQM-10（必須）** 要件の変更理由と承認結果を残す。

成果物には [要件定義テンプレート](../templates/requirements-template.md) を使用できます。データの機密区分には [データ分類とAI利用の対応表](../templates/data-classification-template.md) を使用できます。
