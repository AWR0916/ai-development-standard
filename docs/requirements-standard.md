# 要件定義標準

## 必須事項

- 解決する問題、利用者、期待価値、対象外を明記する。
- 機能要件と非機能要件を分け、一意な識別子を付ける。
- 各要件を観測可能な受入条件に変換する。
- 性能、可用性、セキュリティ、プライバシー、アクセシビリティ、運用性を評価する。
- 入出力データの所有者、機密区分、保存期間、削除方法を定める。
- AIを利用する場合、許容できない出力、人的確認、停止条件を定める。

## 書き方

「適切に」「高速に」「可能な限り」など、判定できない表現を避けます。数値化できない場合も、具体例と判断者を示します。

## 変更時の確認

要件変更では、関連する設計、コード、テスト、運用手順への影響を確認します。変更理由と承認結果を残します。

成果物には [要件定義テンプレート](../templates/requirements-template.md) を使用できます。
