# リリース標準

## 計画

- **REL-01（必須）** リリース計画に、対象バージョン、変更内容、依存関係、実施者、承認者、時間帯、利用者への影響を明記する。
- **REL-02（必須）** データ移行と互換性への影響を評価する。

## 必須事項

- **REL-03（必須）** 再現可能な成果物を識別し、承認済みの変更だけを含める。
- **REL-04（必須）** リリース前検査、バックアップ、監視、ロールバック条件を定める。
- **REL-05（必須）** 秘密情報や環境固有設定を、成果物へ埋め込まない。
- **REL-06（推奨）** 段階的公開が可能な場合は、影響を限定して観測する。
- **REL-07（必須）** 公開後に、主要指標、ログ、警告、利用者影響を確認する。

## 中止と復旧

- **REL-08（必須）** 中止判断者と中止基準を事前に定める。
- **REL-09（必須）** 安全性、データ完全性、重大機能に問題がある場合は、期限より安全を優先する。
- **REL-10（必須）** 復旧後は、原因と再発防止策を記録する。
- **REL-11（必須）** 実施前に [リリースチェックリスト](../checklists/release-checklist.md) を完了する。
