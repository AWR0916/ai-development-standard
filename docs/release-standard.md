# リリース標準

## 計画

対象バージョン、変更内容、依存関係、実施者、承認者、時間帯、利用者への影響を明記します。データ移行や互換性の影響を評価します。

## 必須事項

- 再現可能な成果物を識別し、承認済みの変更だけを含める。
- リリース前検査、バックアップ、監視、ロールバック条件を定める。
- 秘密情報や環境固有設定を成果物へ埋め込まない。
- 段階的公開が可能な場合は、影響を限定して観測する。
- 公開後に主要指標、ログ、警告、利用者影響を確認する。

## 中止と復旧

中止判断者と基準を事前に定めます。安全性、データ完全性、重大機能に問題がある場合は、期限より安全を優先します。復旧後は原因と再発防止を記録します。

実施前に [リリースチェックリスト](../checklists/release-checklist.md) を完了します。
