# テスト標準

## テスト計画

- **TST-01（必須）** 要求とリスクに基づき、単体、結合、システム、受入、セキュリティ、性能、回帰の各テストの要否を決める。
- **TST-02（必須）** 各テストに、対象要求、前提条件、入力、期待結果、合否基準を定める。

## 必須事項

- **TST-03（必須）** 正常系だけでなく、境界値、異常系、権限不足、依存先障害を確認する。
- **TST-04（必須）** 失敗時に原因を特定できる結果を残す。
- **TST-05（必須）** テストデータに、実在する秘密情報や不要な個人情報を使わない。
- **TST-06（必須）** 不安定なテストを放置せず、隔離には責任者と解消期限を設ける。
- **TST-07（必須）** 本番に近い条件で、復旧とロールバックを検証する。

## AI機能の評価

- **TST-08（必須）** AI機能では、正答率だけでなく、有害出力、偏り、根拠性、拒否動作、プロンプト攻撃、再現性、遅延、費用を評価する。
- **TST-09（必須）** 代表例と難例を含む固定評価セットを版管理し、モデル、プロンプト、検索データの変更時に再評価する。

成果物には [テスト計画テンプレート](../templates/test-plan-template.md) を使用できます。完了確認には [テストチェックリスト](../checklists/test-checklist.md) を使用できます。
