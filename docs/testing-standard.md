# テスト標準

## テスト計画

要求とリスクに基づき、単体、結合、システム、受入、セキュリティ、性能、回帰の必要性を決めます。各テストは対象要求、前提条件、入力、期待結果、合否基準を持ちます。

## 必須事項

- 正常系だけでなく、境界値、異常系、権限不足、依存先障害を確認する。
- 失敗時に原因を特定できる結果を残す。
- テストデータに実在する秘密情報や不要な個人情報を使わない。
- 不安定なテストを放置せず、隔離には責任者と解消期限を設ける。
- 本番に近い条件で、復旧とロールバックを検証する。

## AI機能の評価

正答率だけでなく、有害出力、偏り、根拠性、拒否動作、プロンプト攻撃、再現性、遅延、費用を評価します。代表例と難例を含む固定評価セットを版管理し、モデル、プロンプト、検索データ変更時に再評価します。

成果物には [テスト計画テンプレート](../templates/test-plan-template.md) を使用できます。
