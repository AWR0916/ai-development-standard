# セキュリティ標準

## 必須統制

- データと機能を分類し、最小権限でアクセスを制御する。
- 秘密情報は承認済みの保管機構で管理し、定期的に更新する。
- 通信中と保存中の保護要件をデータ分類に応じて定める。
- 依存関係を固定・検査し、既知の脆弱性と供給網リスクを管理する。
- セキュリティ上重要な操作を、改ざん耐性を考慮して監査記録へ残す。
- インシデントの検知、連絡、封じ込め、復旧、振り返りを定める。

## 脅威分析

設計時と重要変更時に、資産、攻撃者、入口、信頼境界、影響、対策、残存リスクを評価します。AI機能ではプロンプトインジェクション、データ流出、過剰なツール権限、汚染データ、危険な自動実行を含めます。

## 外部公開前

[セキュリティチェックリスト](../checklists/security-checklist.md) を完了し、重大または高リスクの未対応事項がないことを確認します。例外は期限付きで承認します。
