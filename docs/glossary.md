# 用語集

本標準で使う用語と略語を定義します。

| 用語 | 定義 |
|---|---|
| ADR | Architecture Decision Record（アーキテクチャ決定記録）。重要な設計判断の背景、選択肢、決定、根拠を残す文書。 |
| AI | Artificial Intelligence（人工知能）。本標準では、生成AI、機械学習モデル、それらを使うサービスやエージェントを含む。 |
| API | Application Programming Interface。ソフトウェア同士が機能を呼び出すための取り決め。 |
| SemVer | Semantic Versioning（セマンティックバージョニング）。`MAJOR.MINOR.PATCH` 形式で互換性を表すバージョン規則。 |
| Pull Request（PR） | 変更をレビューして既定ブランチへ取り込むための依頼。 |
| 必須 | 原則として省略できない規則。適用できない場合は例外として記録する。 |
| 推奨 | 採用しない場合に、その理由を説明できる状態にする規則。 |
| 規則ID | 規則を一意に識別する `SEC-01` のような記号。形式は [バージョニング方針](versioning-policy.md#規則id) に定める。 |
| 例外 | 標準の規則を適用しないことを、期限付きで承認した記録。項目は [導入ガイド](../ADOPTION.md#例外) に定める。 |
| 採用バージョン | 対象リポジトリが基準とする、本標準のリリースタグ。 |
| 受入条件 | 要件を満たしたと判定するための、観測可能な条件。 |
| 信頼境界 | 信頼の程度が異なる領域の境目。外部入力や権限の検証が必要になる位置。 |
| 残存リスク | 対策を講じた後も残り、受け入れの判断が必要なリスク。 |
| 縮退 | 障害や品質低下の際に、機能を限定して安全側で運転を続けること。 |
| 冪等性 | 同じ操作を複数回実行しても、結果が1回の実行と変わらない性質。 |
| ロールバック | 変更を取り消し、変更前の状態へ戻すこと。 |
| プロンプトインジェクション | AIへの入力に指示を紛れ込ませ、意図しない動作をさせる攻撃。 |
