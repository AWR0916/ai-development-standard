# 基本原則

## 1. 人が責任を持つ

AIは判断を支援する道具として扱います。要求、設計、コード、判定、公開に関する最終責任は、役割を割り当てられた人が負います。AIの出力を根拠なく承認してはいけません。

## 2. 検証可能にする

成果物には受入条件、根拠、検証方法を対応付けます。重要な判断は、第三者が経緯と結果を再確認できる形で記録します。

## 3. 最小権限・最小開示を守る

人、AI、ツールには作業に必要な最小限のデータと権限だけを与えます。秘密情報、個人情報、顧客データは、許可された環境以外へ入力しません。

## 4. 小さく安全に変更する

変更はレビュー可能な単位に分割し、自動検査と人の確認を組み合わせます。不可逆または外部影響の大きい操作は、実行前に明示的な承認を得ます。

## 5. 失敗を前提に設計する

誤生成、過信、入力攻撃、依存先障害、データ劣化を想定します。検知、停止、復旧、ロールバックの方法を事前に定めます。

## 6. 継続的に改善する

不具合、インシデント、レビュー指摘、運用指標を標準へ反映します。標準は目的ではなく、より安全で価値ある開発を実現する手段です。
