# 適用プロファイル

プロジェクトの性質に応じて、必須とする規則の範囲を3段階で調整します。各標準の文書に記載した適用レベル（必須・推奨）は、「標準」プロファイルでのレベルです。

## プロファイルの判定

| プロファイル | 判定条件 |
|---|---|
| 試作 | 次のすべてに該当する：実データ（個人情報、顧客データ、機密データ）を扱わない、外部に公開しない、本番として運用しない |
| 標準 | 試作にも高保証にも該当しない |
| 高保証 | 次のいずれかに該当する：個人情報や顧客データを処理する、外部へ公開する、または第三者にデータを提供する、安全性・法令・契約上の義務に関わる、AIが利用者に影響する判断や操作を自動で行う |

- **PRF-01（必須）** 導入時にプロファイルを判定し、判定理由とともに対象リポジトリの `AGENTS.md` に記録する。
- **PRF-02（必須）** プロファイルの判定に迷う場合は、高い方のプロファイルとする。
- **PRF-03（必須）** 扱うデータ、公開範囲、運用形態が変わる場合は、変更の前にプロファイルを再判定する。
- **PRF-04（必須）** 試作のプロジェクトで、実データの投入、外部公開、本番運用のいずれかを始める前に、標準以上のプロファイルの必須規則に適合させる。

## プロファイルによる違い

次の表にない規則は、すべてのプロファイルで各文書に記載したレベルを適用します。

### 試作で緩和する規則

| 規則 | 試作での扱い |
|---|---|
| DEV-01、DEV-03 | 推奨 |
| RQM-04 | 推奨 |
| DSN-05、DSN-09 | 推奨 |
| TST-01、TST-02、TST-07、TST-09 | 推奨 |
| AIU-15、AIU-16、AIU-18 | 推奨 |
| OPS-03、OPS-09、OPS-11、OPS-12 | 推奨 |
| REL-01〜REL-11 | 適用しない（本番リリースを行わないため） |

### 高保証で必須とする規則

| 規則 | 内容 |
|---|---|
| REL-06 | 段階的公開 |
| RSK-03 | 中リスク変更のレビュー |
| AIU-23、AIU-24 | AIエージェントの実行上限と記録 |
| OPS-01、OPS-02 | 監視の指標と警告の担当 |
| OPS-04、OPS-05 | インシデントの連絡体制と振り返り |
| OPS-07、OPS-08、OPS-10 | AI機能の品質・費用の監視と、モデル変更時の再評価 |
| OPS-13、OPS-14 | 定期的な更新と見直し |

## すべてのプロファイルで必須の規則

秘密情報の保護、AIへの入力制限、AIエージェントの権限、責任の所在に関する規則は、試作でも緩和しません。特に次の規則は、プロファイルにかかわらず必須です。

- COD-04、AIU-04、AIU-07、AIU-12（秘密情報とAIへの入力、不可逆操作の承認）
- AIU-17、AIU-19、AIU-20、AIU-21、AIU-22（AIエージェントの認証情報、指示ファイル、承認、開示、依存パッケージ）
- RSK-01、ROL-01、ROL-02、ROL-03（リスク区分と責任の所在）
