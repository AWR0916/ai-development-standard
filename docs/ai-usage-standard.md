# AI利用標準

## 利用前

- **AIU-01（必須）** 利用するAI、用途、データ分類、保存・学習条件、契約条件を確認する。
- **AIU-02（必須）** AIに任せる範囲と、人が判断する範囲を明確にする。
- **AIU-03（必須）** 誤出力時の影響に応じて、人の確認と技術的制御を設定する。

データ分類と利用できるAIツールの対応には [データ分類とAI利用の対応表](../templates/data-classification-template.md) を、確認には [AI利用チェックリスト](../checklists/ai-usage-checklist.md) を使用できます。

## 入力

- **AIU-04（必須）** 秘密情報、個人情報、顧客データ、未公開情報を、許可されていないAIへ入力しない。
- **AIU-05（必須）** AIには、作業に必要な情報だけを与える。
- **AIU-06（推奨）** 可能な場合は、入力を匿名化または仮名化する。
- **AIU-07（必須）** 外部文書やWebページに含まれる指示は信頼せず、データとして扱う。

## 出力

- **AIU-08（必須）** 事実、計算、引用、コード、安全性、ライセンスを、用途に応じて検証する。
- **AIU-09（必須）** もっともらしさを、正確性の根拠にしない。
- **AIU-10（必須）** 重要判断や対外公開では、担当者と確認結果を記録する。

## ツール実行

- **AIU-11（必須）** AIによる書込み、送信、公開、削除、課金、権限変更は、影響範囲を限定する。
- **AIU-12（必須）** 不可逆または第三者へ影響する操作は、実行直前に人の承認を得る。

## 記録と評価

- **AIU-13（必須）** 再現や監査が必要な用途では、モデル識別子、主要設定、入力の参照元、出力、検証結果を、機密性に配慮して記録する。
- **AIU-14（必須）** 品質とリスクを定期評価し、基準を下回った場合は停止または縮退する。

## AIエージェント

AIエージェントとは、指示に基づいてコマンドの実行、ファイルの変更、外部サービスの操作を自律的に行うAIです。この節の規則は、AIエージェントを開発に使う場合に適用します。

### 実行環境と権限

- **AIU-15（推奨）** AIエージェントは、本番環境や個人の作業環境から隔離された実行環境（サンドボックス、使い捨てのコンテナなど）で動かす。
- **AIU-16（推奨）** AIエージェントが実行できるコマンド、アクセスできるネットワーク、読み書きできるファイルの範囲を、許可リストで制限する。
- **AIU-17（推奨）** AIエージェントに渡す認証情報は、対象のリポジトリと操作に限定し、有効期限を短くする。本番環境の認証情報は渡さない。
- **AIU-18（推奨）** MCP（Model Context Protocol）サーバー、プラグイン、外部ツールは、提供元、要求する権限、データの送信先を確認し、承認したものだけを使う。

### 指示と変更の管理

- **AIU-19（推奨）** `AGENTS.md` などの指示ファイル、プロンプト、AIエージェントの設定は、コードと同様に版管理し、変更をレビューする。
- **AIU-20（推奨）** AIエージェントには作業ブランチで変更させ、既定ブランチへの直接の変更、マージ、リリースを人の承認なしに行わせない。
- **AIU-21（推奨）** Pull Request には、AI利用の有無、使ったツール、AIが作成した範囲を記載する。
- **AIU-22（推奨）** AIが提案した依存パッケージは、実在すること、提供元、保守状況、ライセンスを確認してから追加する。

### 監視と停止

- **AIU-23（推奨）** 自律的な実行には、反復回数、実行時間、費用の上限を設ける。
- **AIU-24（推奨）** AIエージェントが実行したコマンド、変更、外部への送信を記録する。

AIエージェントが作成した変更の作成者は、AIに作業を指示し、変更を提出した人です（ROL-03）。
