# テストチェックリスト

## 計画

- [ ] 要求とリスクに基づき、必要なテスト種別を決めた（TST-01）
- [ ] 各テストに、対象要求、前提条件、入力、期待結果、合否基準を定めた（TST-02）
- [ ] テストと要件の対応を記録した（DEV-02）

## 実施

- [ ] 境界値、異常系、権限不足、依存先障害を確認した（TST-03）
- [ ] 失敗時に原因を特定できる結果を残した（TST-04）
- [ ] テストデータに、実在する秘密情報や不要な個人情報を使っていない（TST-05）
- [ ] 不安定なテストを隔離した場合、責任者と解消期限を設けた（TST-06）
- [ ] 本番に近い条件で、復旧とロールバックを検証した（TST-07）

## AI機能

- [ ] 正答率に加え、有害出力、偏り、根拠性、拒否動作、プロンプト攻撃、再現性、遅延、費用を評価した（TST-08）
- [ ] 固定評価セットを版管理し、モデル、プロンプト、検索データの変更時に再評価した（TST-09）

## 完了

- [ ] 受入条件を満たし、重大度が「重大」「高」の不具合が残っていない（REV-07）
- [ ] 残存リスクを記録し、承認を得た（REV-07）
