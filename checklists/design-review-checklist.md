# 設計レビューチェックリスト

## 構成と責務

- [ ] システム境界、利用者、外部依存、信頼境界が示されている（DSN-01）
- [ ] コンポーネントの責務、インターフェース、失敗時の動作が定められている（DSN-02）
- [ ] データの収集から削除までの流れが示されている（DSN-03）
- [ ] 要求との対応が確認できる（DSN-09、DEV-02）

## セキュリティと信頼性

- [ ] 認証、認可、監査、暗号化、秘密情報管理が設計されている（DSN-04）
- [ ] 脅威分析を実施し、残存リスクが記録されている（SEC-07）
- [ ] タイムアウト、再試行、冪等性、縮退、復旧、ロールバックが検討されている（DSN-05）

## AI機能

- [ ] モデルの責務が限定され、入力制御、出力検証、根拠表示、人的介入が設計されている（DSN-07）
- [ ] 確率的出力を前提とした設計になっている（DSN-08）
- [ ] AI機能の脅威を評価した（SEC-08）

## 判断と未決事項

- [ ] 主要な代替案と採否の理由が記録されている（DSN-06、DEV-03）
- [ ] 重大な未決事項に、責任者と期限がある（DSN-10）
- [ ] 運用性と障害モードを確認した（DSN-09）
