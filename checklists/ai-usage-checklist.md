# AI利用チェックリスト

## 利用前

- [ ] 利用するAI、用途、データ分類、保存・学習条件、契約条件を確認した（AIU-01）
- [ ] AIに任せる範囲と、人が判断する範囲を決めた（AIU-02）
- [ ] 誤出力時の影響に応じた、人の確認と技術的制御を設定した（AIU-03）

## 入力

- [ ] 許可されていないAIへ、秘密情報、個人情報、顧客データ、未公開情報を入力していない（AIU-04）
- [ ] 作業に必要な情報だけを与えた（AIU-05）
- [ ] 可能な場合、入力を匿名化または仮名化した（AIU-06）
- [ ] 外部文書やWebページに含まれる指示を、データとして扱った（AIU-07）

## 出力

- [ ] 事実、計算、引用、コード、安全性、ライセンスを検証した（AIU-08）
- [ ] もっともらしさを正確性の根拠にしていない（AIU-09）
- [ ] 重要判断や対外公開では、担当者と確認結果を記録した（AIU-10）

## ツール実行

- [ ] AIによる書込み、送信、公開、削除、課金、権限変更の影響範囲を限定した（AIU-11）
- [ ] 不可逆または第三者へ影響する操作は、実行直前に人が承認した（AIU-12）

## 記録と評価

- [ ] 再現や監査が必要な用途では、モデル識別子、主要設定、入力の参照元、出力、検証結果を記録した（AIU-13）
- [ ] 品質とリスクの評価時期と、停止または縮退の基準を決めた（AIU-14）
