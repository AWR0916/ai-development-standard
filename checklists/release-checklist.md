# リリースチェックリスト

- [ ] 対象成果物、バージョン、変更内容を特定した
- [ ] 必須テストとセキュリティ検査が成功した
- [ ] 未解決事項と残存リスクが承認されている
- [ ] 互換性、データ移行、利用者影響を確認した
- [ ] 設定と秘密情報の扱いを確認した
- [ ] バックアップとロールバックを検証した
- [ ] 中止条件、判断者、連絡先を定めた
- [ ] 公開後の監視項目と確認時間を定めた
- [ ] リリース記録と利用者向け案内を準備した
- [ ] 標準リリースでは、`VERSION` と `CHANGELOG.md` が一致している
- [ ] 標準リリースでは、コミットに対応する注釈付きタグを準備した
