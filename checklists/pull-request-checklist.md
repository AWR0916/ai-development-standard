# Pull Request チェックリスト

## 作成者

- [ ] 目的、変更範囲、対象外を説明した
- [ ] 要求または課題へのリンクを付けた
- [ ] 差分を自己レビューし、目的外変更を除いた
- [ ] ビルド、静的解析、テストの結果を記載した
- [ ] セキュリティ、プライバシー、AI固有リスクを確認した
- [ ] 秘密情報、個人情報、不要なログが含まれない
- [ ] 文書、移行、監視、ロールバックを必要に応じて更新した
- [ ] AI生成部分を人が検証した
- [ ] 標準変更では、バージョンと変更履歴への影響を確認した

## レビュアー

- [ ] 受入条件との対応を確認した
- [ ] 重要な境界条件と失敗時動作を確認した
- [ ] テストが主要リスクを覆っている
- [ ] 残存リスクと例外が明記・承認されている
