# Pull Request チェックリスト

## 作成者

- [ ] 目的、変更範囲、対象外を説明した（REV-02）
- [ ] リスク区分（高・中・低）を判定し、記載した（RSK-01）
- [ ] 要求または課題へのリンクを付けた（DEV-02）
- [ ] 差分を自己レビューし、目的外変更を除いた（REV-01、COD-02）
- [ ] ビルド、静的解析、テストの結果を記載した（COD-09、REV-02）
- [ ] セキュリティ、プライバシー、AI固有リスクを確認した（REV-03）
- [ ] 秘密情報、個人情報、不要なログが含まれない（REV-01、COD-04）
- [ ] 文書、移行、監視、ロールバックを必要に応じて更新した（REV-02）
- [ ] AI生成部分を人が検証した（COD-08）
- [ ] 標準変更では、バージョンと変更履歴への影響を確認した（VER-02、VER-07）

## レビュアー

- [ ] 受入条件との対応を確認した（REV-03）
- [ ] 重要な境界条件と失敗時動作を確認した（REV-03）
- [ ] テストが主要リスクを覆っている（REV-03、TST-01）
- [ ] 残存リスクと例外が明記・承認されている（REV-07）
- [ ] 高リスク変更を承認する場合、自分がその変更の作成者ではない（REV-04、ROL-02）
