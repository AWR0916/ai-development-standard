# セキュリティチェックリスト

- [ ] 資産、データ分類、信頼境界を特定した（SEC-01、SEC-07）
- [ ] 認証と認可を最小権限で設計した（SEC-01、DSN-04）
- [ ] 外部入力を境界で検証している（COD-03）
- [ ] 秘密情報を承認済みの方法で管理している（SEC-02）
- [ ] 通信中・保存中のデータ保護を確認した（SEC-03）
- [ ] 依存関係と既知の脆弱性を確認した（SEC-04）
- [ ] 監査ログに必要情報があり、秘密情報を含まない（SEC-05、COD-04）
- [ ] プロンプト攻撃、データ流出、過剰権限を評価した（SEC-08）
- [ ] 障害検知、連絡、封じ込め、復旧手順がある（SEC-06）
- [ ] 高・重大リスクが解消済み、または期限付きで承認済み（SEC-09、SEC-10）
